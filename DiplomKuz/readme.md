# Инструкция по первичной настройке новой функциональности

## Общие сведения
Перед началом работы с новой функциональностью необходимо выполнить ряд действий в рабочей информационной базе.  
Эта инструкция описывает порядок настройки и проверки системы.  
*Все перечисленные справочники, регистры и документы доступны в подсистеме «Добавленные объекты».*

---

## 1. Создание Телеграм-группы и бота
1. Создайте группу и бота в Телеграм.  
2. Эти объекты нужны для отправки уведомлений специалистам о созданных документах **Обслуживание клиента**.  
3. Уведомления формируются при создании нового документа, а также при изменении даты и ФИО специалиста.  

---

## 2. Заполнение констант
Заполните cледующие константы:

- `Абонентская плата` — заполняется из справочника **Номенклатура** соответствующим по смыслу наименованием, при необходимости создайте нужную номенклатуру;  
- `Работы специалиста` — заполняется из справочника **Номенклатура** соответствующим по смыслу наименованием, при необходимости создайте нужную номенклатуру;  
- `ВКМ токен ТГБот` — токен телеграм-бота;  
- `Идентификатор группы ТГ` — ID группы в Телеграм.  

> Без заполнения констант интеграция с телеграм и автозаполнение документов работать не будут.  

---

## 3. Условия оплаты сотрудников
Заполните регистр сведений **Условия оплаты сотрудников**:  
- процент от продаж у специалистов,  
- оклады у всех сотрудников.  

---

## 4. Графики работы
1. В справочнике **Графики работы** создайте вид графика (например, пятидневка).  
2. В подсистеме **Сервис** откройте обработку **Заполнение графика работы**:  
   - укажите период (год),  
   - задайте выходные дни через запятую (например, `6,7` — суббота и воскресенье),  
   - выберите ранее созданный график.  
3. Нажмите **Заполнить**.  
4. В регистре **График работы** проверьте корректность заполнения.  
5. Для расчетов по календарным дням отдельно создайте и заполните график **Календарные дни**.  

---

## 5. Пользователи и права доступа
1. Создайте пользователя для каждого сотрудника.  
   - Пример: сотрудник *Бухгалтер Волков В.В.* → пользователь *Волков Виктор Васильевич*.  
2. На вкладке «Права доступа» назначьте профиль группы доступа:  
   - для бухгалтеров — `БухгалтерИТФирмы`,  
   - для кадровика — `Кадровик расчетчик`.  
3. Профили групп доступа являются поставляемыми и изменению не подлежат.  

---

## 6. Дополнительные инструкции для сотрудников
1. **Кадровик**: создаёт сотрудников в справочнике **Физические лица** и назначает подразделение (нужно для заполнения документов «Начисление заработной платы»).  
2. **Бухгалтер**: использует обработку **Массовое создание актов** для автоматического формирования реализаций за месяц (выбирается предыдущий месяц).  
3. **Менеджер**: создаёт договоры вида *Абонентское обслуживание* с заполнением:  
   - даты начала и окончания договора,  
   - стоимости часа работы,  
   - суммы абонентской платы.  
4. Все пользователи должны знать: если константы *Работы специалиста* и *Абонентская плата* не заполнены, документ не будет сформирован.
